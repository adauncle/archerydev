## 改动

### 1. 新增 `sql/extensions/dingtalk_oa/services/oa_callback_handler.py`（核心）

`handle_oa_callback(event)` 把钉钉回调事件映射到本地 `workflow_audit` 状态变更：

| 钉钉事件 | 推进动作 |
|----------|---------|
| `bpms_task_change` + `finish/agree` | 推进 audit 到 `next_audit`；无下级 -> `WorkflowStatus.PASSED` |
| `bpms_task_change` + `finish/refuse` | audit 标 `WorkflowStatus.REJECTED` |
| `bpms_instance_change` + `finish` | 仅同步 `external_status=APPROVED/REJECTED`（不重复推进） |
| `bpms_instance_change` + `terminate/abort` | audit 标 `WorkflowStatus.ABORTED` + `external_status=TERMINATED` |
| 重复回调 | noop（`select_for_update` + 检查 `current_status` 已变） |
| 未知 processInstanceId | skipped |

每个推进动作：
1. `select_for_update` 加锁防并发
2. 检查 `current_status=WAITING`（已推进则 noop）
3. 推进 `current_audit` / `next_audit` / `current_status`
4. 写 `WorkflowAuditDetail`（audit_user=operator, audit_status=PASSED/REJECTED, remark 含审批意见）
5. 写 `WorkflowLog`（operation_type=PASS/REJECT, operator_display="<name> (via 钉钉)"）
6. 同步 `sql_workflow.status` (workflow_review_pass / workflow_review_reject / workflow_abort)
7. 触发 `async_task(notify_for_audit)` 给提交人/执行人

**actor 翻译**：钉钉 `StaffId` 反查 `Users.ding_user_id` 找 Archery 用户；
找不到就 fallback 用 `StaffId` 字符串 + `StaffName (via 钉钉)` 显示名。
