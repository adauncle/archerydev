# v0.1.5-prod — 装 goInception + 配 SysConfig

**日期**: 2026-07-22
**类型**: feat (新依赖)
**Tag**: v0.1.5-prod (待打)

## 问题

测试 /submitsql/ 点「SQL检测」时，弹窗报错：
```
GoInception检测语法报错，请注意检查系统配置中GoInception配置，
错误信息: '\connect' argument 1 must be str, not None
```

## 根因

1. **goInception 服务没装** —— server 上 `which goInception` 没结果
2. **SysConfig 没配** —— `sql_config` 表被 TRUNCATE 过，`archer_config.get("go_inception_host")` 返回 None
3. **MySQLdb 拿到 host=None** —— 抛 `'\connect' argument 1 must be str, not None`

## 修复

1. **装 goInception v1.3.0** (Go 单体二进制, 12.6MB)
   - 下载: `https://github.com/hanchuanchuan/goInception/releases/download/v1.3.0/goInception-linux-v1.3.0-94-g2f06c61b95.tar.gz`
   - 装到: `/opt/goinception/goInception`
   - 配置: `/opt/goinception/config/config.toml`
   - systemd service: `/etc/systemd/system/goinception.service` (17 行最小 systemd 219 兼容)
   - 监听: `0.0.0.0:4000`
2. **SysConfig 写 4 个 goInception 字段** (sql_config 表):
   - `go_inception_host=127.0.0.1`
   - `go_inception_port=4000`
   - `go_inception_user=root` (任意非空字符串，goInception 不真鉴权；空字符串会让 MySQLdb 拒)
   - `go_inception_password=''`
3. **重启 gunicorn** 让 ORM cache 刷新

## 验证

```python
>>> from sql.engines import get_engine
>>> from sql.models import Instance
>>> inst = Instance.objects.get(instance_name="测试 MySQL 8.0")
>>> engine = get_engine(instance=inst)
>>> review = engine.execute_check(db_name="archery_dev", sql="CREATE TABLE test ...")
>>> len(review.rows)
2  # 之前是 OperationalError
```

整条链路：Archery MySQLEngine → GoInceptionEngine → goInception (4000) → 目标 MySQL (3306) 全部通。

## 重要的代码认知

`MySQLEngine.__init__` 里：
```python
self.inc_engine = GoInceptionEngine()  # 注意：没有 instance 参数
```

所以 `GoInceptionEngine` 在生产路径上是**无 instance 状态**运行的，
`get_connection()` 会走 `SysConfig` 分支连 goInception。

**如果有人手动 `GoInceptionEngine(instance=inst)`**，会导致
`get_connection()` 走 `self.host/self.port`（目标 MySQL 而非 goInception），
连 MySQL 时用户用 OS user → 拒。
