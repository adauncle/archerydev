# 2026-08-24 gh-ost + 字段 diff 开发人员宣讲手册

## 摘要

Archery 二次开发 gh-ost 无锁 DDL 变更 + 字段 diff 检测的开发人员宣讲手册 — 架构讲解 + 关键设计 + 踩坑教训 + 业务场景 + 5 分钟宣讲脚本, 给开发人员拿去给业务团队宣讲时心里有底。

## 调整说明

之前一版是给业务 RD + DBA 的"操作手册" (教用户怎么点按钮), 8/24 用户调整定位为"给开发人员宣讲和参考使用" (教开发怎么讲这个功能)。重写:
- 去掉所有版本号 (v0.4.5 / v0.3.0 / v0.3.x 等), 改成"gh-ost 集成" "字段 diff 检测" "DDL 智能回滚" "碎片回收" 等描述性命名
- 去掉"操作步骤"风格, 改成"架构 + 关键设计 + 踩坑"风格
- 加 5 分钟宣讲脚本 (给开发拿去给业务团队讲)
- 加 10 个现场答疑 (开发宣讲时可能遇到)
- 加 3 个宣讲避坑 (不要给业务 RD 讲架构细节等)

1. **概览: 两个功能解决两件事** - 4 个事故场景举例 (字符集丢失 / 大表锁表 / DDL 半残 / 碎片)
2. **架构概览** - 整体架构图 + 关键模块 + 核心数据模型
3. **字段 diff 检测 (核心算法)** - 3 步骤 + 11 规则 + 字符集丢失根因 + 边界场景
4. **gh-ost 集成 (架构 + 状态机)** - 进程模型 + 8 状态机 + runner / poller 关键设计 + 切流机制 + zombie socket 防御
5. **任务管理 + 权限模型** - 4 perm + 角色视角 + AJAX perm 教训 + 业务定位文案修正
6. **碎片回收 (3 决策详解)** - ENGINE+ROW_FORMAT+CHARSET 3 层防护 + rebuilt_* 字段 + ALTER 子句列
7. **DDL 智能回滚 (A+B 方案)** - 5 种 DDL 智能逆向 + B 方案兜底 + 顺序踩坑教训
8. **踩坑教训 (8 条)** - GoInception panic / 字符集丢失 / DBA 兜底定位 / AJAX perm / drill 严谨 / 业务配置 / 文案修正 / 默认权限
9. **业务场景案例 (4 个真实)** - 8 月份真实踩坑, 跟业务团队共鸣
10. **宣讲要点 + 答疑** - 5 分钟脚本 + 10 个现场答疑 + 3 个宣讲避坑

## 3 个宣讲避坑

1. **不要给业务 RD 讲架构细节** — 业务 RD 不关心 poller 怎么实现, 只关心"我能点哪个按钮"
2. **不要承诺"gh-ost 一定不锁表"** — 切流期间 atomic 模式阻塞 1-3 秒, 诚实说"业务零感知" 而不是"零阻塞"
3. **不要演示未跑过的功能** — 4 个案例是 8 月真实跑过的, 拿来宣讲有底气, 临时加的"未来会做"别演示
