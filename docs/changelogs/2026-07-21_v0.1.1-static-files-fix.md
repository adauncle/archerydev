# 2026-07-21 · v0.1.1-prod 静态文件修复

## 症状（用户截图）

prod 登录页 `http://172.20.2.134:9003/login/` 浏览器显示**裸 HTML**（无 CSS/JS），控制台 5 个错：

```
Refused to apply style from 'http://172.20.2.134:9003/login/' (MIME 'text/html' is not a supported stylesheet)
Refused to execute script from 'http://172.20.2.134:9003/login/' (MIME 'text/html' is not executable)
Uncaught ReferenceError: $ is not defined (at login/:123:5)
Uncaught ReferenceError: $ is not defined (at login/:147:5)
```

## 根因（两个 bug 叠加）

### Bug 1：common/static 整个目录没在 git 里

`.gitignore` 第 18 行 `dist/` 和第 28/50 行 `static/` 是**根级相对模式**，默认匹配所有层级的同名目录。
结果 `common/static/`（含 122 个 bootstrap/jquery/dist/img 等文件）被全部排除。

`git ls-files common/static` 返回 0 行。
但 `STATICFILES_DIRS` 指向 `common/static`，collectstatic 应该收集 —— 可问题是 `common/static` 在 prod 上**根本不存在**（git clone 时没拉）。

### Bug 2：STATICFILES_STORAGE 选错导致 manifest 失败

`common.storage.ForgivingManifestStaticFilesStorage`（继承 `ManifestStaticFilesStorage`）：
- 依赖 `staticfiles.json` manifest 做 hashed 名称映射
- 但 `sql-formatter/` / `watermark/` / `sb-admin-2/` / `notice/` 几个文件在 `common/static/` 里**有重复路径冲突**（多个 app 的同名文件）
- collectstatic 时 `post_process` 报 "Found another file" 警告后**静默失败不写 manifest**
- 没有 manifest → whitenoise 找不到 hashed 文件 → fall through 到 Django URL → 302 → /login/

## 修复

### commit f366066 — `.gitignore` 限定根级
```diff
- static/
+ /static/        # 只匹配根目录，不影响 common/static
- dist/
+ /dist/          # 同上
```
`git add common/static` 引入 122 文件（39673 行）。

### commit 1a9aea0 — `STATICFILES_STORAGE` 换 whitenoise 推荐方案
```diff
- STATICFILES_STORAGE = "common.storage.ForgivingManifestStaticFilesStorage"
+ STATICFILES_STORAGE = "whitenoise.storage.CompressedStaticFilesStorage"
```
whitenoise 6.x 在 manifest 缺失时会**直接 fallback 到 STATIC_ROOT 文件系统查找**（不依赖 hashed 路径），所以重复文件警告不影响 serving。
附带收益：自动 gzip 压缩。

## 修复后验证

```
/static/bootstrap/css/bootstrap.min.css -> HTTP 200 (121457 bytes, text/css)
/static/jquery/jquery.min.js              -> HTTP 200 (86927 bytes, text/javascript)
/static/dist/css/login.css                -> HTTP 200 (524 bytes, text/css)

```

`common/static/.gitignore` 还在警告（"Found another file" 8 个），但实际无影响。

## 教训

1. **.gitignore 默认是 path-agnostic 匹配** —— `static/` 会匹配 `common/static/`
2. **上游 settings.py 的 storage 不能照搬** —— `ForgivingManifestStaticFilesStorage` 是上游为了 7.x 的旧版浏览器加的 hash 缓存，我们这种内部工具不需要，反而引入新坑
3. **whitenoise 6.x 比想象的鲁棒** —— 没 manifest 也能 serve（虽然不是最佳实践）
4. **dedup 警告不要无脑忽略** —— 它会阻止 manifest 写入，进而影响 hashed-URL 渲染
5. **gunicorn 启动时 pkill -f 'gunicorn.*9003' 不一定杀干净** —— 用 `pgrep -f` 先拿 PID 再 `kill`，必要时 SIGKILL
