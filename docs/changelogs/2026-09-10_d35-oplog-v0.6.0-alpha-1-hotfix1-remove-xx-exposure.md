# D35-OpLog v0.6.0-alpha-1 hotfix 1: 移除 ## 注释在页面底部暴露 (2026-09-10 15:40)

## 业务反馈 (9/10 15:33 业务方截图)
- 业务方访问 hly_billing pair 详情页, 在页面最下方看到一行 `## CUSTOM-MODIFIED: v0.6.0-alpha-1 9 类 action + IP/UA 列 + detail 表格化 @ 2026-09-10 @ mavis ## 关联: docs/plans/2026-09-10_d35-oplog-roadmap.html 阶段 1.2 / 1.3 / 1.4 / 1.5 ## 9 类 action: create / edit / enable / disable / one_click / bulk_import / add_table / delete_table / transform_change`
- 多个列表页面 (同步历史 / 基本信息 / 同步表清单) 底部都显示同样一行
- 业务方不能接受, 立刻反馈要求修复

## 根因
v0.6.0-alpha-1 commit 2a2abe9 推 110 prod 时, pair_detail.html line 347-349 我在 HTML 注释区写注释时, 用了 markdown 风格 `## CUSTOM-MODIFIED: ... ##` 而**没有用 HTML 注释 `<!-- -->` 包裹**:

```html
<!-- tab 4: 操作日志 -->
<!-- CUSTOM-MODIFIED: D35-Pending 操作日志真渲染 @ 2026-09-09 @ mavis -->
<!-- 关联: docs/plans/2026-09-04_ddl-sync-w2-d35-pending-audit-log.md (方案 A) -->
## CUSTOM-MODIFIED: v0.6.0-alpha-1 9 类 action + IP/UA 列 + detail 表格化 @ 2026-09-10 @ mavis  <!-- 暴露给业务方 -->
## 关联: docs/plans/2026-09-10_d35-oplog-roadmap.html 阶段 1.2 / 1.3 / 1.4 / 1.5  <!-- 暴露给业务方 -->
## 9 类 action: create / edit / enable / disable / one_click / bulk_import / add_table / delete_table / transform_change  <!-- 暴露给业务方 -->
<div class="tab-pane fade" id="tab-logs">
```

浏览器把 `##` 当文本渲染了 (跟 markdown 标题相似但其实只是字面字符, 浏览器不解析 markdown, 不会变成 h1/h2, 但作为文本内容显示在 HTML body 里)。

## 修法
1. **HTML 注释区**: 把 3 行 `## ...` 全部改成 `<!-- -->` HTML 注释包裹
2. **CSS 块 (保险)**: pair_detail.html line 60-62 的 CSS 块里 `## ...` 也改成 `/* ... */` CSS 注释 (虽然 CSS 块浏览器不显示, 但保险起见改一致)
3. **Python 注释统一**: 之前 v0.6.0-alpha-1 我在 .py 文件里也用了 `## CUSTOM-MODIFIED:` 双 # 注释, PowerShell 替换脚本统一改成单 `# CUSTOM-MODIFIED:` (跟 v0.5.0 / D35-Pending 风格一致)
