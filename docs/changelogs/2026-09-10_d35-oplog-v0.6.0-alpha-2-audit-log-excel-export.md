## 实现
1. **新 view 端函数 `pair_audit_log_export`** (sql/extensions/ddl_sync/views/__init__.py):
   - 复用 D33 `pair_history_export` 的 openpyxl 套路
   - 字段: ID / 操作类型 / 操作人 / 详情 (JSON) / 客户端 IP / 浏览器 UA / 操作时间 / 补录数据
   - 表头加粗 + 8 列宽 (ID 8 / 操作类型 14 / 操作人 14 / 详情 60 / IP 18 / UA 30 / 时间 20 / 补录 12)
   - 文件名: `ddl_sync_audit_log_pair<pair_id>_<timestamp>.xlsx` (ASCII safe, 防 GBK 编码)
   - 权限: `view_ddlsyncpair` (跟同步历史一致)
2. **新 URL 路由** (sql/extensions/ddl_sync/urls.py):
   - `path("pair/<int:pair_id>/audit_log_export/", views.pair_audit_log_export, name="pair_audit_log_export")`
3. **模板按钮** (sql/extensions/ddl_sync/templates/ddl_sync/pair_detail.html):
   - tab 4 操作日志标题栏右上角, 跟 D33 同步历史导出按钮同位置
   - 用 `<a class="ddlsync-btn-export">导出 Excel</a>` 跟 D33 同步历史按钮 CSS class 一致
   - `{% if perms.ddl_sync.view_ddlsyncpair %}` 守卫, 没权限不显示按钮

## 实战新发现 (跨项目可复用, 1 条)
**Excel 导出按钮跟同步历史保持一致** (D33 + v0.6.0-alpha-2 实战新发现) - 跨项目做"审计日志 / 同步历史"类功能, Excel 导出按钮必:
1. 同一个 tab 内右上角位置 (`flex justify-content: space-between` 布局)
2. 同一个 CSS class (`ddlsync-btn-export`, 在 `<style>` 块定义 `background: #67C23A; color: #fff`)
3. 同一个 URL 模式 (`/app/<model>/<id>/<feature>_export/`)
4. 同一个 view 函数套路 (`openpyxl.Workbook()` + `ws.column_dimensions[X].width` + ASCII safe filename)
实战踩坑: 业务方对"导出 Excel" 按钮的位置 / 颜色 / 下载文件名预期都很敏感, 跟同步历史不一致会让业务方怀疑"是不是新做的", 复用 D33 套路让业务方一眼熟悉. D33 历史背景: 8/26 实战新发现, D38 续 7 必演练老工单新工单两边 (避免上游 bug 借我们推的代码被触发)
