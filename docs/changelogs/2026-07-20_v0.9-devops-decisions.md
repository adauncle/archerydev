11. 初始化策略：migrate + seed
12. GitHub reviewer：项目 owner

### 新增 §5.6 钉钉回调 Cloudflare Tunnel 配置

- 7 个步骤：login → create → config → DNS → systemd → 验证 → 钉钉后台
- 完整 `cloudflared` config.yml 示例
- `cloudflared.service` systemd 单元（Type=notify）
- 5 条故障排查命令

### 关键安全点

- **HTTP 但用 IP 白名单**：10.x / 172.16-31.x / 192.168.x / 127.0.0.1
- **外网直接访问会被 403**
- **钉钉回调额外限制只允许 127.0.0.1**（Cloudflare Tunnel 转发来的）
- **密钥分级管理**：
  - 服务器密钥 → `/etc/archery/` (600 权限)
  - GitHub Secrets → 用于 CI/CD
  - GPG 备份密码 → 独立文件
  - **绝不能上传到 git**
