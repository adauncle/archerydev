# 碎片回收 admin 详情链接 404 — 8/25 修

## 症状

DBA 浏览器点 `progress_rebuild.html` 进度页 **"查看 admin 详情"** 按钮，404 Page not found。

URL: `http://172.20.2.134:9003/admin/sql/extensions%20ddl_gh_ost/ddlghosttask/77/change/`

Django admin 报：
```
Page not found (404)
Using the URLconf defined in archery-urls, Django tried these URL patterns, in this order:
1. admin/ [name='index']
2. admin/login/ [name='login']
...
admin/sql/<model_name>/* (单层 app_label)
```

Django admin URL 模式是 `admin/<app_label>/<model_name>/<id>/change/`，
但模板拼成了 `admin/sql/extensions%20ddl_gh_ost/...`（嵌套路径 + URL 编码空格），admin 找不到 model。

## 根因

`progress_rebuild.html` 第 159 行 URL 写错：
```html
<!-- 错的 -->
<a href="/admin/sql/extensions%20ddl_gh_ost/ddlghosttask/{{ task.id }}/change/">
```

**正确 URL**（Django `_meta.app_label` = `ddl_gh_ost`）：
```html
<!-- 对的 -->
<a href="/admin/ddl_gh_ost/ddlghosttask/{{ task.id }}/change/">
```

`progress.html` (gh-ost 进度页) 第 175 行用对了格式，只有 rebuild 进度页错。

## 验证

134 dev Django shell 验：
```python
>>> DdlGhostTask._meta.app_label
'ddl_gh_ost'
>>> DdlGhostTask._meta.model_name
'ddlghosttask'
>>> reverse("admin:ddl_gh_ost_ddlghosttask_change", args=[77])
'/admin/ddl_gh_ost/ddlghosttask/77/change/'
```

## 修法

2 处模板/脚本 URL 拼错，统一改对：

| 文件 | 行 | 改前 | 改后 |
|------|---|------|------|
| `sql/extensions/ddl_gh_ost/templates/ddl_gh_ost/progress_rebuild.html` | 159 | `/admin/sql/extensions%20ddl_gh_ost/ddlghosttask/{{ task.id }}/change/` | `/admin/ddl_gh_ost/ddlghosttask/{{ task.id }}/change/` |
| `sql/extensions/ddl_gh_ost/services/notify.py` | 98 | `/admin/sql/extensions%20ddl_gh_ost/ddlghosttask/{task.id}/change/` | `/admin/ddl_gh_ost/ddlghosttask/{task.id}/change/` |

## 教训 (跨项目可复用)

1. **Django admin URL 永远是 `admin/<app_label>/<model_name>/...`，不是 app 路径**
   - 即使 app 在 `sql/extensions/ddl_gh_ost/`，`_meta.app_label` 还是 `ddl_gh_ost`
   - 模板里写嵌套路径（`/admin/sql/extensions/...`）一定 404
2. **URL 拼写必查 `_meta.app_label` + `_meta.model_name`**，不要从文件路径脑补
3. **用 `{% url 'admin:app_label_model_name_change' id %}` 比手写路径稳**（这次没改是为了最小 diff，但下次重构应该改）
4. **gh-ost 进度页跟 rebuild 进度页两套模板需保持 admin URL 一致**，未来新增任务类型时记得照抄
