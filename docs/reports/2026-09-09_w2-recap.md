## 💡 跨项目可复用实战新发现 (5 大类 30+ 条)

### 1. 推生产部署 (D14, D31, D35, D38 续 7)
1. **必 `git diff a..b --name-only` 列推送清单** (D38 续 7) — 实战踩坑: D35 push 漏列 sql/views.py
2. **三环境 md5 对比必覆盖全部 sql/ + archery/ + common/ 文件** (D38 续 7) — 不能只看推过的几个文件
3. **手工改上游文件必 commit** (D38 续 7) — D35 手工 sed 改 3 文件没 commit, 110 prod / 134 dev / Windows 都跟 git HEAD 不一致
4. **必 kill + 拉新 qcluster** (D24 实战新发现)
5. **必演练 3 个 sync_status 工单** (D25 实战新发现)
6. **110 prod 走 systemd + mock env** (D35 push 实战) — 110 prod .env 缺 CAS_SERVER_URL, 启动 gunicorn 必传 mock env
7. **推 110 prod 必演练老工单 + 新工单两边** (D38 续 8) — 实战踩坑: 9/3 推 views.py 后老工单引用已删 Group 500
8. **演练业务方场景用 `Client.force_login(user)`** (D38 事故) — 不要 set_password 真改业务方密码

### 2. 浏览器 / 前端 (D36 二级, D37, D38, D38 续, D38 续 2, D38 续 9, D38 续 10)
9. **演练必先推代码再演练** (D38 续 3 实战) — Windows 本地演练 view 跑通 ≠ 110 prod 真的生效
10. **134 dev 跟 Windows 本地 git 仓库不同步, ssh 端 view 跑通才行** (D36 二级踩坑)
11. **分页链接必用绝对 URL** (`{% url 'app:view' pk %}` + query) (D38) — 不用相对 URL `?query`
12. **gunicorn 推完 template 必 restart** (D38 补充) — Django DEBUG=True 理论每次重读但 gunicorn prefork + file descriptor 缓存
13. **业务方浏览器层中间件排查** (D38 续) — Archery 登录是 JS AJAX 不是标准 HTML form
14. **演练 + 真 HTTP + 业务方浏览器三层对比金标准** (D38 续 2) — 110 prod 没 reverse proxy, 业务方 Chrome 无痕模式 = 100% 排除扩展
15. **client-side filter 不持久化, 必 server-side filter** (D38 续 3) — form GET + view 过滤 + URL 持久化
16. **template 加 button 必查 JS 双向走查事件监听器** (D38 续 4) — 静态文件浏览器会缓存, 改 JS 必通知业务方硬刷
17. **innerHTML 注入必 escape HTML 防 XSS** (D38 续 4) — `&<>"'` 5 个字符
18. **"看 X 不能操作 X" 必拆 2 个 helper** (D38 续 5) — _is_admin_or_dba 看全量 + _can_operate 操作
19. **审批人组 + 端点硬墙双层防护** (D38 续 5) — 前端按钮 can_operate 隐藏 + 后端 _require_change_perm 端点 403
20. **Python f-string 里 `'\''` 是 2 个单引号不是 1 个** (D38 续 6) — 必用 `repr()` 验证实际输出
21. **`document.execCommand("copy")` 在 Chrome 95+ 经常失效** (D38 续 6 / 续 9) — 屏幕外 textarea + HTTP context 都不靠谱
22. **modal 一键复制必用 user gesture 触发** (D38 续 10) — Chrome 95+ 静默失败只针对**自动触发**, user gesture 触发的 copy 正常 work
23. **一键复制 业务方 HTTP context 必弹 modal 兜底** (D38 续 9) — navigator.clipboard.writeText + execCommand 两条都不靠谱, 必弹 modal + 可见 textarea + 提示手动 Ctrl+C
