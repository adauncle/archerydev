字段 diff 检测 · 创建工单时智能比对

在 SQL 提交页面一键检测 ALTER 变更，提前发现类型/字符集/排序规则等隐式变化，避免生产事故。覆盖 8 维字段属性，11 条风险规则。

生产事故复盘：MODIFY COLUMN 没带字符集
改前：status VARCHAR(100) CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci
改后：ALTER TABLE x MODIFY COLUMN status VARCHAR(50)（省略 CHARSET/COLLATE）
MySQL 自动用 表默认字符集 替换，跨表 JOIN 索引失效，性能暴跌 + 用户客诉。

📐 联动架构 · 同一端点 POST /gh_ost/column_diff/ 服务两处：
  • SQL 检测结果页: JS 检测到 ALTER TABLE ... MODIFY/ADD/DROP 时自动 fetch, 默认折叠, 高风险自动展开
  • 详情页大表 alert: DBA 手动点 "字段 diff" 按钮 fetch (跟现有三按钮并列)
  • 端点职责单一: 只做列定义 diff, 不耦合 SQL 检测 / gh-ost 启动逻辑
  • 失败回退: column_diff 报错时静默 fallback, 不影响 SQL 检测主体
